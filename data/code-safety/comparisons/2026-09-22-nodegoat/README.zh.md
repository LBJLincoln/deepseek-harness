# NodeGoat：企业与其替代方案的对比

[English](README.md) | 中文

一个数字若旁边没有下限和上限，就没有意义。本记录用同一把尺子为审查同一个应用的三种方式打分，让读者自行判断这套 harness 的价值，而不是听我们说。

这里的一切都在 **OWASP NodeGoat 修订版 `c5cb68a`** 上，与企业记录 `2026-09-21-nodegoat-3` 所依据的修订版和 18 项基准真值相同。当一条发现落在某个已知问题三行之内时，即算作命中该问题，这是 `compare.mjs` 与 `recall.mjs` 共用的规则。问题的数量与位置从未展示给任何一层。单模型层与企业层运行**同一个模型**（sonnet）；两者之间唯一不同的就是 harness。

## 三个层级

| 层级 | 是什么 | 18 项召回 | 发现数 | 每条发现都在其行号处经过验证 | 墙钟时间 | 成本 |
| --- | --- | ---: | ---: | :---: | ---: | ---: |
| Semgrep | 商用静态分析，96 条社区规则，无模型 | 4 / 18 (22%) | 16 | 否 | 数秒 | $0 |
| 单个前沿模型，一次 | 单个 sonnet 会话，无部门，无验证器 | 15 / 18 (83%) | 23 | 否 | 113 s | $0.36 |
| Daliesk 企业 | 六个部门、一个验证器与集成；同一个 sonnet | 13 / 18 (72%) | 47 | 是，验证器退出码 0 | 1356 s | 订阅 |

## 如何诚实地解读

**扫描器是下限。**Semgrep 捕获约四分之一的已知问题，且一个都不确认；人仍须打开每一处命中。它快而免费，但不是一次审查。

**在小型应用上，单个前沿模型很强。**在 NodeGoat 的 44 个文件上，一次 sonnet 通过捕获了 18 之 15，比企业多两个。我们如实报告。但它的 23 条发现未经验证，安全团队须手工复核全部 23 条；运行是非确定性的，第二次通过会返回不同的集合；它不留下记录、没有按领域的深度、没有证书。它是一个快速的意见，而不是可审计的结果。

**在这个小应用上，企业以两个原始召回换取单次通过给不了的东西。**它的 47 条发现每一条都经机械验证确实存在于其所引行号处。它呈现 47 条真实发现，对单次通过的 23 条，检视的攻击面翻了一倍多。它留下完整记录——7 个 agent 会话、190 步、294 次工具调用、7 份证书——审阅者可以审计。而且它产出另外两层给不了的证书。

**企业真正领先之处是规模。**在 44 个文件上，单个模型能把整个应用一次装进上下文。本概念验证面向的应用有数千个文件；在那里单次通过装不下代码，而并行运行的领域部门加验证器，是既彻底又可信的唯一途径。本记录是小应用情形，此时单模型处于最强、差距处于最窄。

## 对比交给改进循环的东西

对比不仅是一张成绩单，也是改进 harness 的循环的输入。逐问题打分后，它精确指出每种方式的盲点：

- **单模型与企业都漏掉同样的两个**身份认证被破坏问题（`NG-A2-2a`、`NG-A2-2b`）。一个共同的硬骨头，如今是一个有名字的目标。
- **单次通过捕获了部门漏掉的三个**：服务端请求伪造（`NG-SSRF`，`app/routes/research.js`）、正则表达式拒绝服务（`NG-REDOS`，`app/routes/profile.js`）、日志注入（`NG-A1-3`）。它们指出应拓宽的部门范围。
- **企业捕获了单次通过漏掉的一个**：静态敏感数据（`NG-A6-1`），部门领域深度的一次胜利。

那份差距清单就是部门技能应关闭的待办，也是应对每个目标运行对比、而非只运行一次的理由。

## 文件

`comparison.json` 是机器记录：三个层级、逐问题矩阵与差距。`t0-semgrep-findings.json` 与 `t1-single-model-findings.json` 是两个现场层级的发现，已规范化为发现结构；`t0-semgrep-raw.json` 与 `t1-single-model-meta.json` 保留各生产者自身的输出。`enterprise-trajectory.json` 是企业记录的来源与逐发现轨迹。用以下命令重新生成成绩单：

```sh
node data/code-safety/tools/compare.mjs <findings.json> data/code-safety/targets/nodegoat.ground-truth.json
node data/code-safety/tools/assemble-comparison.mjs data/code-safety/targets/nodegoat.ground-truth.json data/code-safety/comparisons/2026-09-22-nodegoat
```
