Four workflows, one deterministic spine

Every stage is a plugin. Semantic agents propose inside structured outputs; deterministic services fold the session log, run the verifiers, and hold the authority together with the humans who sign. The same log that runs the fleet is the dataset that trains the model.

§1

Principles shared by the four workflows

Each one is enforced by something the repository already has, or names the plugin that will enforce it.

§2

Meta-agent roster

Every agent is a preset composition. Semantic agents emit forced schemas; deterministic ones fold or gate. No agent judges its own work.

§3

Structured hand-offs

Every semantic-to-deterministic edge names one of these schemas. A rejected output returns to its producer with the validation error as the directive.

§4

Scoreboard schema · SessionFacts

One row per session. D fields fold from the session log or the run report; S fields come from judge sessions that are themselves logged.
