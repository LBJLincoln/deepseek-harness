# Agentic coding harnesses and their releases, June to September 2026

Three movements define the window. Vendor harnesses converged on the seams this harness already has (cross-session agent messaging, per-agent models and permission modes, worktree isolation, network sandboxing, event-driven and self-scheduled operation). The tool protocol under every bridge changed shape. And one vendor switched off an open-source harness with about 104k stars on a date, which is the argument for model-agnosticism in one sentence.

## What changed

- **Vendor harnesses.** Claude Code reached 2.1.263 (<https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md>): 128K inline output limits, a file-based subagent system prompt, a skill doctor that reports unused skills with their context cost, `SendMessage` and `ListAgents` across sessions, `model` and `permissionMode` on agent definitions, model-switch hooks, network sandboxing with domain allowlists, worktree isolation, and background goal monitoring. Codex CLI shipped 0.153.0 to 0.153.4 on 2026-09-03 and 04 (<https://github.com/openai/codex/releases>) with plugin-marketplace management, app-server reconnection, and MCP tool approvals scoped to app accounts; 0.147.0 brought portable agent plugins and an opt-in MCP 2026-07-28 implementation. OpenHands shipped about ten releases between 2026-07-30 and 08-27 (<https://github.com/All-Hands-AI/OpenHands/releases>) with automation phases, an LLM pre-flight validation that rejects a misconfigured profile before a run, per-run cost tracking, and a readiness gate for issues. Amp shipped agent-to-agent spawning, self-scheduling agents that wake themselves (2026-07-21), and event-driven Orbs reacting to CI failures, issues, alerts, or any HTTP request (2026-07-23) (<https://ampcode.com/news>).
- **A harness switched off.** Google stopped serving Gemini CLI and the Code Assist extensions for individual tiers on 2026-06-18 and moved them to a closed-source binary (<https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/>); secondary reporting puts the retired Apache-2.0 repository at about 104k stars.
- **The open field.** A star-ranked survey of 2026-08-29 (<https://pinggy.io/blog/best_open_source_cli_coding_agents/>, secondary) lists OpenCode and the upstream DeepSeek Harness at about 202k and 203k stars, Codex CLI 119k, Pi 98k, OpenHands 85k, Cline 67k, Goose 54k under the Linux Foundation, and Aider 48k with no commits since May 2026. The upstream read directly on 2026-09-07 (<https://github.com/deepseek-ai/deepseek-harness>) is MIT, developer preview, about 214.7k stars over about 15,210 commits; this fork adds the improvement, verification, components, and governance groups it lacks, so merge cost is a standing line item and the harness alone is not the moat.
- **The protocol under the bridge.** The MCP 2026-07-28 revision (<https://modelcontextprotocol.io/specification/2026-07-28/changelog>) is stateless: no initialize handshake or session id, a mandatory `server/discover`, `resultType` on every result, `ttlMs` and `cacheScope` on lists, method headers validated against the body, multi round-trip requests replacing server-initiated sampling, elicitation, and roots on a twelve-month deprecation, and JSON Schema 2020-12 tool schemas. The ecosystem migrates dual-era, serving both revisions; as of mid-window no major client had shipped it, so servers lead clients.
- **Interoperability and long tasks.** Harbor (<https://github.com/harbor-framework/harbor>, Apache-2.0) runs arbitrary agents against Terminal-Bench 2.x, SWE-Bench, and Aider Polyglot across Docker, Daytona, Modal, and other sandboxes, with an installed-agent contract (fresh container, headless run, post-run parse of tokens and cost) and an adapter list that includes `dsh`; Harbor-Index followed on 2026-07-06. Terminal-Bench Challenges (<https://www.tbench.ai/news/terminal-bench-challenges>, 2026-06-18) are three single-task benchmarks with 10,000 to 500,000-line solution scopes that twelve-hour runs did not finish.
- **Harness as a measured object.** HarnessOpt-Bench (<https://arxiv.org/abs/2608.06301>), HarnessDev (<https://arxiv.org/abs/2609.01437>), and EvoHarnessBench (<https://arxiv.org/abs/2609.04280>) score harness work itself; The Scaffold Effect (<https://arxiv.org/abs/2607.22585>) finds harness choice moves tokens per solved task up to 41.9 times at 0 to 8 points of pass rate. Prime Agent (<https://github.com/PrimeIntellect-ai/prime-agent>, MIT, about 20.1k stars) is the closest public self-improving harness; its refinements are unversioned text with no certificate and no paired experiment.

## What Daliesk adopts

1. A dual-era MCP face on the tool bridge: `server/discover`, `resultType`, `ttlMs` and `cacheScope` on outbound tool lists, and multi round-trip requests for elicitation, beside the current revision.
2. Pre-flight route validation at plan freeze: a fleet cell with a misconfigured route fails before the shift, not inside it.
3. A Harbor adapter for this harness, so external leaderboards run it unmodified and Harbor's token and cost contract becomes a recorded outcome of every cell.
4. Event-driven wake for shifts, appended to the shift's ledger session before any cell is planned, so an externally triggered shift replays like a cadenced one.
5. Model-agnosticism stays the product argument: a route is a plugin, and a vendor's product is one route among several.
6. One Terminal-Bench Challenge run through the program seam as the external validity check for certified partial progress on a client-shaped deliverable.
