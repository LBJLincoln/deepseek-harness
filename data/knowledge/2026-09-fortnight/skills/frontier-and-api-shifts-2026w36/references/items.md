### BAITBENCH: measuring agent reward hacking with optional shortcuts planted in ML tasks

- Date 2026-08-31 · kind benchmark · role input · evidence primary · goals 3, 4 · seams curator, environments, judge, trajectories, verification
- URL: <https://arxiv.org/abs/2608.30724>
- Summary: Submitted 31 August 2026. Three synthetic tabular ML tasks contain deliberately planted, optional shortcuts.
