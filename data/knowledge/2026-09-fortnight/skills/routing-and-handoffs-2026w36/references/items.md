- Summary: Submitted 31 August 2026. - URL: <https://arxiv.org/abs/2608.29460>
- Summary: Submitted 29 August 2026. When coding agents meet defective test infrastructure they may hardcode outputs or edit tests. The paper gives agents a structured escalation tool to report the defect instead. ### Knowing When to Ask for Help: Bayesian Self-Escalation in Hierarchical LLM Agents (arXiv:2608.24087)

- Date 2026-08-25 · kind paper · role input · evidence primary · goals 1, 4 · seams agent-loop, guard/session-budget, llm
- URL: <https://arxiv.org/abs/2608.24087>
- Summary: Frames intra-generation handoff as optimal stopping over a learned competence posterior — explicitly not raw entropy, since a model can be confidently wrong — with a closed-form myopic threshold, a proven time-varying threshold structure, and a regret bound making posterior calibration, not the decision rule, the binding constraint. Real-model check on MBPP sanitized (257 tasks, Qwen2.5-Coder 1.5B->7B, execution-defined labels): streaming escalation reaches 74.7% at 0.98x junior-only compute where post-hoc routing needs 1.41x for 75.0%; junior 62.3%, senior 80.9%, with 43 of 257 tasks failed by both. - Adopt: Adopt the framing that aborting a doomed run pays for the escalation — that is where the cost saving comes from, not from picking better. ### Most of the LLM Routing Gap Is Task Type (arXiv:2608.23023)

- Date 2026-08-25 · kind paper · role baseline · evidence primary · goals 1, 4 · seams environment-runner, experiments, preset, scorekeeper
- URL: <https://arxiv.org/abs/2608.23023>
- Summary: Fourteen models x 294 questions (7 task types x 3 languages), executed twice at temperature 0 and seed 42 through one gateway. 221 of 4,116 model-question cells (5.37%) flip their correct bit on identical re-execution, and billed cost moves -3.81%. Oracle minus best-single is 29 items (9.86pp); a static task-type lookup fitted once recovers 21 of 29 (72.4%), and adding language leaves 6 of 294 (2.04%) — below the reproducibility floor. ### The Handoff Tax: Continuing Non-Native Trajectories in LLM Agents (arXiv:2608.24358)

- Date 2026-08-25 · kind paper · role baseline · evidence primary · goals 1, 2, 4 · seams agent-loop, compaction, session/telemetry, subagent
- URL: <https://arxiv.org/abs/2608.24358>
- Summary: The strongest negative result in the window, from AWS Agentic AI. SWE-bench Verified, all 500 instances, mini-swe-agent, Haiku 4.5->Opus 4.7 and GPT-5.6 Luna->Sol, seven difficulty-calibrated switch points, 58,000 agent runs / 2M API calls / 36B tokens. Raw mid-trajectory escalation recovers under half the cheap-to-strong gap (QRec 47% Claude, 36% GPT) at 4.0x/6.1x cheap-model cost; for Claude, $1.61 against $0.72 for simply starting on Opus (CSRet -285%). - Adopt: Adopt as the design constraint on every escalation feature: escalation carries a measurable tax, downshift is the profitable direction, and the compaction seam is the lever (drop context going up, preserve it going down). Adopt QRec/CSRet as the reporting pair in the scorekeeper. This is the paper H1-H3 derive from.

### CacheRouter: dual-path tool routing with cache-preserving main-model isolation

- Date 2026-08-24 · kind paper · role input · evidence primary · goals 1, 2 · seams budget-policy, mcp-client, session-projection-cache, token-meter, tools
- URL: <https://arxiv.org/abs/2608.22708>
- Summary: Submitted 24 August 2026. Progressive tool disclosure keeps the prompt small but destabilises the request prefix that prompt caching rewards. CacheRouter keeps core tools fixed in the main model's request and reaches long-tail tools through a separate routing channel. The prototype reports token-level cache hit rates of 90.99% and 95.2%, with input cost falling to about 12.0% and 8.0% of a no-cache baseline under DeepSeek pricing where cached tokens cost roughly a thirtieth of cache-miss tokens, evaluated on 55 functional queries and a 30-turn dialogue, with automated tool registration allowing runtime tool-set changes without destabilising the cached prefix.
- Adopt: Directly applicable: our MCP bridge and skill catalogue both want to add tools mid-session, which is the exact prefix-destabilising move this paper prices. Adopt the two-channel split — a stable core tool set in the main request, long-tail discovery behind a router — and measure it with `token-meter` on a DeepSeek route where the 30x cache ratio makes the effect visible. Read alongside Factory's routing post: both conclude the cache prefix is the real constraint.
- Tags: cost, deepseek, mcp, prompt-cache, tool-discovery

### Factory: Why model routing must be in the harness

- Date 2026-08-24 · kind framework · role threat · evidence primary · goals 1, 2, 4 · seams budget-policy, experiments, llm, llm-retry, scorekeeper, session-projection-cache, token-meter
- URL: <https://factory.ai/news/model-routing-belongs-in-the-harness>
- Summary: Factory published production measurements on 24 August 2026 arguing that model routing belongs in the harness rather than in a gateway. Droid's routing cut aggregate cost 58% against pricing every call at the frontier model, with a median session saving of 76%, measured by re-pricing each completed session as if every call had used the frontier model. Quality was reported as matched across eight production measures including task completion, command and test failures, repeated edits and delivered artifacts. The cache argument is the load-bearing one: fully uncached routing costs 2.12x an all-frontier single-model baseline at turns 61–150 and 2.37x at turns 151–200, whereas cache-aware routing stays between 0.19x and 0.28x of the same baseline. Factory also records session state at each choice, the model selected and the result that followed, and feeds that back into the router policy. Terminal-Bench 2 and Legacy-Bench are named for comparative testing.
- Adopt: This is the closest published statement of our own thesis by a competitor, and the numbers are the useful part: a router that ignores prefix cache turns a saving into a 2x loss past turn 60. Any Daliesk routing plugin must price a switch against the cache miss it causes and must log the state, the choice and the outcome as session events so `experiments` can replay paired seeds. Do not copy the closed feedback loop uncritically — a router trained on its own production outcomes is a reward-integrity surface, and ours needs a tamper verdict.
- Tags: competitor, cost, factory, prompt-cache, routing

### Disagree to Explore, Agree to Commit: Routing-Guided Test-Time Scaling for Software Agents (arXiv:2608.22191)

- Date 2026-08-23 · kind paper · role baseline · evidence primary · goals 1, 2, 4 · seams agent-loop, experiments, workflow
- URL: <https://arxiv.org/abs/2608.22191>
- Summary: Uses native MoE router traces (expert ids and gate weights per token and layer) as a free internal signal to steer exploration within a trajectory and arbitrate between separately sampled attempts, with no external judge and no selection-time test execution. SWE-bench Verified, gpt-oss-20b/120b at three reasoning efforts plus Qwen3.6-35B-A3B; K=4 attempts, n=16 candidates per step, 50-step budget. Macro-average resolved rate 44.9% (uniform) -> 48.2% (Risa) / 48.3% (Risa-H), against 48.0% for plain text consensus and a 60.9% oracle.
