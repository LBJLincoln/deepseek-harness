# Agent Note: The public-repository task factory: function tasks with hidden tests from permissively licensed public code

Status: implemented

English | [中文](2026-09-27-public-repository-task-factory.zh.md)

## Problem

Goal 3's binding constraint is environments. The Proving Ground bench holds 44 hand-authored environments, the [completion family](../../proposed/architecture/2026-09-22-completion-task-factory.md) multiplies them into 246 children that the product models saturate, and the [repository-derived family](../../proposed/architecture/2026-09-22-repository-derived-environments.md) proved that a documented, tested module is an answer key with a verifier attached but yielded two children from `packages/util`, because its rules bind a module to one spec that imports only it and `vitest`. Hundreds of verifiable, uncontaminated-by-construction function tasks exist in public repositories that this repository never wrote: small utility libraries whose every export carries a JSDoc block and whose tests are per-function files under a runner the bench can approximate. Reaching them means generalizing the repository factory along the axes public suites vary on — a module with a dependency closure, a test that imports several modules or a barrel or a namespace, a block the shim cannot run beside blocks it can, `node:test` beside vitest — and attaching to every child what a task built from third-party code must carry: its source, its pinned commit, its licence, and the data-use terms that licence admits.

## Decision

`tools/synthesize-public-tasks.ts` derives function-implementation tasks from the sources `tools/public-sources.json` pins: for each, a name, the clone URL, the full commit, the SPDX id, the licence file's path and SHA-256, the directory mirrored into a child's `src/`, and the directories read. The factory fetches each commit into the gitignored cache `.proving-ground/public-sources/<name>` by `git init`, `git fetch --depth 1 origin <commit>`, and `git checkout FETCH_HEAD`, reusing a cache whose head is that commit; a source whose fetch fails, whose licence file is missing or has another digest, whose licence text reads as another id than the one declared, or whose id is outside MIT, ISC, BSD-2-Clause, BSD-3-Clause, and Apache-2.0 is dropped before anything is read, and the census says which and why. Those five licences admit a derived task as training material with attribution kept, so every child's `task.json` carries `terms: { purposes: [delivery, training, evaluation], attribution: LICENSE }` beside `public: { source, url, commit, license, licenseFile, licenseSha256, copyright, module, tests }`, the source's licence text sits at the workspace root as `LICENSE`, immutable, and the README's attribution section repeats the source, commit, licence, and copyright line. A trajectory on a public child is training material only where the route's `dataUse/terms` admit training as well; the base bench composition pins evaluation alone, so the terms a child carries state what its licence permits, not what a given run produced.

The pure half, `tools/public-environments.ts`, generalizes `repository-environments.ts` (which it imports for transpiling, function location, stubbing, tiers, ids, and case entries) rather than copying it. Function location gained the two forms public sources use: a function exported by a later `export default name` or `export { name }` statement, and an implementation preceded by bodiless overload signatures, which inherits the first overload's JSDoc when it has none of its own. A test's imports decide its fate: `vitest` and `@jest/globals` named bindings within `describe`/`it`/`test`/`suite`/`expect`/`vi`/`expectTypeOf`/`assertType` and the four hooks, or `node:test` bindings within its own set, set the framework; a test that imports no runner is read as the `expect` family under globals; `node:` built-ins are kept verbatim, so a `node:test` suite's `assert` import runs as written; a relative import is followed through `export { x } from`, `export { default as x } from`, and `export * from` chains to the declaring file, which must lie under the source root, and the import is re-pointed at that file's workspace path, a namespace import becoming a frozen object of the members the test reads; any package import rejects the test. The modules a test imports are the modules it judges, its blocks are pooled per module across every test that imports it, and the module's dependency closure — transitive relative imports, each re-pointed to the workspace, `node:` built-ins allowed and packages not — is what a child's `src/` holds, the stub in the one module and every other file untouched. A block is dropped on its own, and counted by reason, when its body or any enclosing level's own statements reference `vi` or `mock`, chain an `expect` outside the matcher subset or through `.resolves`/`.rejects`/`expect.*`, register a hook, nest a runner call, or use `require`/`import()`; a block registered through `it.each`, `it.skip`, a loop, an options object, or a non-literal title is skipped and counted by form; a test whose every block is dropped or skipped is rejected as keeping none. The factory runs the pooled cases against the reference twice and drops any it fails in either run — the shim or the transform falling short of that block, or a block whose verdict depends on the host's load, which must leave the corpus rather than refuse a correct implementation in a cell — then writes one child per documented exported function whose stub fails at least one remaining case, the tier set by that count under the repository family's `--tier-bands`, and its `--admit` step runs `admit.mjs` over the output, deletes what admission refuses, and writes `REFUSED.json` and `CENSUS.json` — per source the fetch status and reason, modules, tests, usable tests, rejections by category, blocks dropped by reason and skipped by form, candidates, written, and admitted; overall the skips by reason, the cases the reference failed, and the written and admitted counts by tier.

`expect-shim.mjs` is no longer inlined into a public child's cases: the factory writes it into the workspace as `test/expect-shim.mjs`, immutable, and each case imports it, so a case is a few hundred bytes and the file that decides an assertion is visible to the implementer, who learns nothing about the cases from it. The shim gained the matchers the candidate suites use most beyond the repository subset — `toBeDefined`, `toBeNaN`, `toBeTypeOf`, `toBeInstanceOf`, `toHaveProperty`, `toContainEqual`, `toMatchObject`, `toThrowError`, `toThrowErrorMatchingInlineSnapshot`, `toBeGreaterThanOrEqual`, `toBeLessThanOrEqual`, `toBeCloseTo` — and the runtime no-ops `expectTypeOf` and `assertType`, each a few lines; `MATCHER_SUBSET` names them all, and the repository family admits them too. `register-public-environments.ts` registers what admission kept under the `bench` kind in domain `public`, with `detail.public`, `detail.terms`, and `detail.completion`, refusing a child whose named attribution file is missing or that carries no cased check; `overlays/with-public.cordis.yml` mounts it beside the base composition and `overlays/registry-only-with-public.cordis.yml` is the keyless variant the registrar e2e boots.

## Alternatives considered

**Widen the repository factory in place.** Rejected: its rule set is a contract the repository family's census and spec pin (one spec, only the module and `vitest`, whole-spec rejection), and public suites break every one of those rules at once; a second factory over the same pure helpers keeps the repository family's behavior stable while the public one generalizes, and the shared pieces (`transpile`, `analyzeModule`, `stubFunction`, `tierFor`, `taskId`, `caseEntries`) live in one place.

**Inline the shim into every case, as the repository family does.** Rejected on size: with hundreds of children at several cases each, an inlined shim of several kilobytes per case would have put the family well past the committed size the bench can carry, and the shim's presence in the workspace reveals nothing the prompt does not already say. The repository family keeps its inlined form because its two children do not pay the cost.

**Copy a barrel into the workspace and import it.** Rejected: a barrel pulls its whole library into every child, and the tests that reach a function through `index` are the same tests that name it, so following the re-export chain to the declaring file keeps the workspace to the module's own closure.

**Shim `vi.fn()` and the mock matchers, or chai's `assert`, or unroll `it.each` and loops.** Deferred rather than rejected: each is a larger extension than a matcher, the census counts what each would recover (blocks dropped for `vi`, tests rejected for a package, blocks skipped by form), and the sources that need them are named in the allowlist so a later slice can measure its gain.

**Accept a copyleft or unlicensed source with its terms marked non-training.** Rejected: a task built from third-party code is a derived work whose every copy and trajectory carries the licence, and the bench has no consumer for a task it may not train on; excluding those sources at the licence check keeps the family uniform in the terms it admits.

**Allow closure files outside the source root, mapped under a second directory.** Rejected for this slice: the workspace's `src/` mirrors one directory so a child's paths read as the library's own, and the census shows what the rule costs (remeda's tests that import helpers from its `test/` directory).

## Consequences

The allowlist names ten sources — es-toolkit, remeda, simple-statistics, @antfu/utils, case-anything, string-ts, ms, date-fns, ufo, and change-case, nine MIT and one ISC, each pinned to a commit and a licence digest — and the checked-in run reads all ten: 2,027 modules and 808 test files, 537 of them usable; 627 documented functions reach a stub run and 560 become children — 224 of tier 2, 240 of tier 3, and 96 of tier 4 — while 65 are reached by no case and 2 repeat a taken name, 4 pooled cases are dropped because the reference fails them, and admission refuses none, so `REFUSED.json` is `[]`. Every child is `heldOut: false`, in domain `public`, judged on its cases alone, and carries its source's licence text and terms, so a trajectory export that filters by the child's terms can admit it for training when the route's terms also do. The committed family is 21.7 MiB in 9,745 files in the working tree, most of it duplicated content git stores once (the shim, each source's licence, and the closure files that recur across a source's children): 7.9 MiB of distinct content in 2,980 blobs, 1.7 MiB as a delta-compressed pack, beside the completion family's 23 MiB in 2,354 files. The family's tests are the sources' own, published under the same licences and read by any model trained on public code, so a certificate on it measures implementation from documentation only to the extent the implementer has not memorized the suite; the smoke results below say how far that goes for the product models. The repository family's spec changed in two expectations: an implementation preceded by an overload signature now inherits that signature's JSDoc, and `toMatchObject` is inside the subset. Two repository gates treat the family's children as task content rather than documentation: the bilingual-pairing manifest excludes the directory, and `verify-md-links` does not scan its READMEs, because a child's README repeats its source's JSDoc verbatim and a link in it (remeda's `clone` names `#isPlainObject`) is the source's documentation site's to resolve.

## Verification

`node tools/synthesize-public-tasks.ts --admit` over the ten pinned sources wrote the family and its census as stated above; a later run over freshly fetched checkouts of the same commits reproduced `CENSUS.json` byte for byte and every child's cases, and `admit.mjs` run again over the directory admitted the same 560 and refused none. A run made while the host was loaded had dropped one more reference case, remeda's real-timer `debounce.test.ts › can check for inflight timers (trailing)`, which is why the reference now runs each case twice. `examples/headless-agent/tests/proving-ground-public-family.spec.ts` covers the pure module line by line — licence classification and terms, allowlist validation, resolution and workspace paths, runtime imports and specifier rewriting, export maps and barrel following, `analyzeTest` over vitest, namespace, `node:test`, hook, drop, skip, and rejection cases, the added matchers as case programs, task files and READMEs — and runs the factory end to end over a local repository reached by a `file://` URL, with a relicensed and an unreachable sibling dropped and censused. `proving-ground-bench.e2e.ts` boots `registry-only-with-public.cordis.yml` and finds `code:ms--implement-parse` among at least one hundred public cells beside the curated tasks. The smoke fleet `public-smoke-sonnet` — one admitted child per pinned source, ten cells on the middle model, seed 1, sealed, two at a time — certified 10 of 10, 8 at the first attempt, in 307 s of wall time and 606 s of cell time (13 to 210 s per cell, median 48 s), recorded as [`2026-09-27-bench-public-smoke-sonnet`](../../../../data/proving-ground/2026-09-27-bench-public-smoke-sonnet/manifest.json): the family runs end to end on the product route with the sources' own tests as the verdict, and the two cells that needed a second attempt were refused at the first by held-back corner cases the documentation does not spell out; how far the family ranks models is unmeasured until a larger fleet, and the open-weight route, run on it. Gates: the host compiler face, lint, knip, `verify-cordis-config`, `verify-translation-pairing`, `verify-agent-note-format`, `doc-sync`, and `scripts/proving-ground.spec.ts` pass.
