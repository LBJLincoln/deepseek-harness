## What this commit contains

`packages/verification/verification/src/` — the event-sourced `ctx.completionStandards` service core, modeled file-for-file on `packages/goal/goal` (the repo's closest sibling):

- `types.ts` — pure types: `StandardId`/`CheckId` (branded), `StandardRef` CAS fence, `StandardCheck {id, outcome, run}`, `RelaxedCheck {check, evidence}`, `CompletionStandardSnapshot {id, revision, goalId, checks, relaxed}`, `CheckResult`, `CertificateIsolation ('none'|'process'|'host')`, `VerificationCertificate`, `DirectiveRequest`, `RunOutcome`, `StandardView`, `AuthorStandardRequest`. Imports `GoalId` from `@deepseek-ai/dsh-goal/types`.
- `runtime.ts` — `VERIFICATION_CHANGE_VERSION = 1`, `StandardId()`/`CheckId()` brand constructors, `isKebabCase()`, `VerificationError extends HarnessError`.
- `domain.ts` — durable payloads + `SessionEventMap` merges for FOUR events: `verification/standard` (author|extend full snapshot), `verification/relaxation` (checkId + full post-relaxation snapshot; evidence rides the snapshot's appended relaxed entry), `verification/certificate` (fully passing run: exact current ref, one pass result per active check in check order, isolation, recordedAt), `verification/directive` (root cause + detail + current ref). Plus `FoldedVerification` and `VerificationErrorCode`.
- `fold.ts` — strict decoders (exact sorted key sets, kebab ids, normalized text, version check) + replay fold: author requires fresh revision-one standard for a new goal (supersedes only a different goal's standard); extend is append-only on checks, preserves relaxations and createdAt, monotone updatedAt; relaxation removes exactly its named check and appends exactly one evidenced relaxed entry; certificate must cover the exact current revision/goal/check order and clears on any later mutation; directive requires the exact current ref and increments `directivesIssued`.
- `index.ts` — `CompletionStandardService extends Service` (`ctx.completionStandards`, `static inject = ['agents']`), schemastery `Config {maxChecks:256, maxTextChars:16384}`, WeakMap session cache + incremental sync, verbs: `get`, `author`, `extend`, `relax`, `recordRun` (all-pass → certificate append; any fail → `{certified:false, failures}` with no event — the directive is the durable channel), `issueDirective`, `certified`, `assertCertified(agent, goalId)` (the orchestrator's admission primitive before `ctx.goals.complete()`). Exact-live-agent identity check like GoalService.

Design deltas vs the Agent Note to fold back into it (step 8): the note names three events; implementation adds `verification/standard` as the durable standard-lifecycle event. Enforcement posture for this slice: certificate admission is advisory (`assertCertified` for the caller + invariant detection); in-`GoalService` enforcement needs a completion-admission extension point deferred to the preset/driver slice.
